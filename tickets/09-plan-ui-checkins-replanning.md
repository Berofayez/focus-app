# 09 – Plan UI, check-ins and re-planning

**Goal:** Close the loop: plan -> do -> report -> adapt.

**You will learn:** Combining everything, prompt design with history, good ADHD UX.

**Steps:**
1. Onboarding intake (goal, level, hours/day, best energy hours, useful apps/sites).
2. Weekly view and an editable daily plan.
3. End-of-session result (done / partly / stuck) is sent to the AI for gentle re-planning (shrink tasks, reschedule, no shaming).
4. Weekly summary of wins and emergency-pass reasons.

**Test:** Mark a session "stuck" and confirm the next plan is easier; miss a day and confirm the plan adapts.

**Done when:** You can run a real week with the app.
